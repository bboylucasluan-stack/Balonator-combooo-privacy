1. Introdução

O Balonator Combooo é um jogo 100% offline desenvolvido em Unity por Lucas Luan Diniz Lourenço. Levamos sua privacidade a sério.

2. Dados que NÃO Coletamos

Nós NÃO coletamos, NÃO armazenamos em nuvem e NÃO vendemos nenhum dado pessoal. O jogo não tem anúncios, não tem login e não tem analytics.

3. Permissão de Câmera - Controle de Papelão

O Balonator Combooo utiliza a câmera para a mecânica de captação de movimento do controle de papelão. A imagem é processada 100% localmente, em tempo real, apenas para detectar o controle. Nenhuma foto ou vídeo é gravado, salvo ou enviado para a internet.

4. Link Externo para o Controle de Papelão (Blogger)

Para jogar, o App oferece um botão opcional "Criar Controle" que abre o navegador para um site externo no Blogger com a imagem para imprimir e colar no papelão. Este acesso é opcional e acontece fora do App. O site do Blogger possui a Política de Privacidade do Google: https://policies.google.com/privacy

5. Motor Unity

Na versão atual, desativamos todos os serviços de coleta de dados da Unity.

6. Serviços de Terceiros

Exceto pelo link opcional para o Blogger (Google), o App não integra outros SDKs.

7. Privacidade das Crianças

Jogo Livre para todas as idades. Como não coletamos dados, não coletamos dados de crianças (COPPA, LGPD, GDPR).
